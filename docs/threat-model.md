# Threat model (v0.1 — for security review)

**Assets:** content users process (JSON payloads, tokens, keys, customer PDFs, identity documents); integrity of the served bundle; availability of the portal.

**Trust boundaries:** (1) user's browser ↔ private-network server; (2) the server ↔ the outside world (must be none); (3) the build pipeline ↔ the registry of npm packages.

**Actors:** curious or careless user; malicious insider; attacker who reached the private network; compromised upstream npm package.

## Threats and controls (STRIDE, mapped to OWASP 2021)

| #   | Threat                                                                                  | OWASP    | Control in place                                                                                                                                                                                                                                                                     | Status                              |
| --- | --------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------- |
| T1  | Pasted content leaks to a third party                                                   | —        | All Phase 1 tools run in the browser; no runtime calls to any external host; CSP `connect-src 'self'` blocks exfiltration even by injected code                                                                                                                                      | ✅                                  |
| T2  | Script injection via formatted HTML/Markdown/SVG output                                 | A03      | Output is shown as text in Monaco; the Markdown preview is DOMPurify-sanitised; CSP forbids inline script and `eval`                                                                                                                                                                 | ✅                                  |
| T3  | Malicious dependency runs `eval`/fetch                                                  | A03, A08 | CSP blocks `eval`/`new Function` (only `wasm-unsafe-eval` for WebAssembly); ESLint bans eval in app code; licence + audit gates in CI                                                                                                                                                | ✅ (SRI and signed images: Phase 4) |
| T4  | Portal reachable from outside                                                           | A01      | Binds to 127.0.0.1 by default; `ALLOW_CIDRS` allow-list; intended behind an internal ALB                                                                                                                                                                                             | ✅ (network scan at go-live)        |
| T5  | Path traversal on the server                                                            | A01      | Paths resolved inside `dist/` only; `..`, encoded `..` and NUL rejected; no client-supplied paths reach the filesystem                                                                                                                                                               | ✅ tested                           |
| T6  | Clickjacking / framing                                                                  | A05      | `X-Frame-Options: DENY`, `frame-ancestors 'none'`                                                                                                                                                                                                                                    | ✅                                  |
| T7  | Weak crypto chosen by mistake                                                           | A02      | Web Crypto + hash-wasm only (no home-grown primitives); AES-ECB not offered; MD5/SHA-1/CRC32 labelled "legacy/not secure"; GCM recommended; PBKDF2 600k iterations; KATs against NIST/RFC vectors                                                                                    | ✅                                  |
| T8  | Secrets linger after use                                                                | A04      | No server storage; "Clear all" on every tool; localStorage holds tool IDs only (validated on read); clipboard only on explicit Copy                                                                                                                                                  | ✅                                  |
| T9  | ReDoS / heavy input freezes the tab                                                     | A04      | Regex tester runs in a Web Worker that is terminated after 5 s; debounced live parsing elsewhere; PDF work in a worker                                                                                                                                                               | ✅ tested                           |
| T10 | Decompression bomb                                                                      | A04      | Streaming gunzip aborts past max(10× input, 10 MB), hard cap 200 MB (SEC-4)                                                                                                                                                                                                          | ✅ tested                           |
| T11 | Server resource abuse                                                                   | A04      | 60 s request/header timeouts; `/api` rate limit 30/min/IP; container CPU/memory limits                                                                                                                                                                                               | ✅ (PDF API: Phase 2)               |

## Residual risks / decisions needed

- **No audit log** (by design): organisations deploying DevToolkit should record their acceptance of this.
- `style-src 'unsafe-inline'` is required by Monaco and Framer Motion (inline style attributes). Script injection remains blocked.
- web-tree-sitter (Java formatter) contains an `eval` path for WebAssembly modules that embed JS; the bundled Java grammar does not use it, and the CSP would block it if it ever ran (verified in the browser smoke test).
